# Code for SAITAMA 紹介文

この文書は、Facebookバックアップから作成したアーカイブ資料をもとに、Code for SAITAMAのアーカイブサイト制作時に参照しやすいよう整理した紹介文です。事実関係は主にFacebookページのプロフィール情報、イベント記録、投稿記録に基づきます。

## 概要

Code for SAITAMAは、埼玉県を拠点に、テクノロジー、オープンデータ、地図、地域課題解決をつなぐ活動を行ってきた非営利団体です。Facebookページ上の記録では、2014年6月にページが登録され、2014年から2024年までの間に、マッピングパーティ、アイデアソン、ハッカソン、もくもく会、ミートアップ、電子工作ワークショップ、防災・災害対応に関する活動など、多様な市民参加型イベントが記録されています。

活動の中心にあるのは、地域の課題を一部の専門家だけで扱うのではなく、市民、行政、大学、企業、地域団体が情報を持ち寄り、実際に手を動かしながら考え、試し、形にしていく姿勢です。2015年のイベント資料では、Code for Saitamaの活動内容として「テクノロジーを活用したアクションを創発する活動を支援していく非営利団体」と記されています。この言葉は、Facebookアーカイブ全体に見られる活動の性格をよく表しています。

## 活動の特徴

### 1. オープンデータを地域の実践につなげる

Code for SAITAMAの活動では、オープンデータが繰り返し重要なテーマとして扱われています。2015年のオープンデータアイデアソン、オープンデータハッカソン、さいたま市マッチングファンド関連イベント、International Open Data Dayへの参加、アーバンデータチャレンジ関連の活動などを通じて、公共データを「公開されている情報」にとどめず、地域の課題を考え、可視化し、活用するための材料として扱ってきました。

イベント記録では、埼玉県、さいたま市、和光市などのオープンデータ活用への言及があり、地域の情報を共有しながら、データの利活用を支援する姿勢が示されています。単にデータを眺めるのではなく、アイデアソンで課題やアイデアを整理し、ハッカソンで実際のサービスや資料、プロトタイプにつなげる流れが特徴です。

### 2. OpenStreetMapとマッピングパーティを重視する

Facebookアーカイブに残るイベントの中で特に多いテーマが、OpenStreetMapやマッピングに関する活動です。浦和、大宮、岩槻、川越、熊谷、戸田、盆栽村、別所沼公園など、埼玉県内外のさまざまな場所を対象に、まち歩き、地域情報の収集、地図への反映、地域資源の可視化を行ってきました。

マッピングパーティは、地図づくりをきっかけに地域を見る活動でもあります。建物、道路、消火栓、電柱、観光資源、バリアフリー情報、防災に関わる情報など、地域の中にある情報を参加者が歩いて確認し、記録し、共有することで、まちの見え方を変えていく実践になっています。

### 3. アイデアソンとハッカソンで「考える」と「作る」を往復する

Code for SAITAMAのイベントには、アイデアソンとハッカソンが多数含まれています。2014年の「Hack for クリテリウム」、2015年のオープンデータアイデアソン・ハッカソン、2016年の主題図づくり、2017年の観光を考えるアイデアソン／ハッカソン、2020年のSDGsアイデアソン・ハッカソンなど、テーマは時期ごとの地域課題や社会的関心に応じて変化しています。

これらの活動では、プログラマーだけでなく、地域の課題を知る人、アイデアを出す人、データを集める人、資料を作る人、発表する人など、多様な参加者が想定されています。アーカイブ上のイベント説明にも、プログラマーに限らず、市民が求めるニーズを整理したり、プレゼン資料を作ったり、データを集めたりする人も不可欠であるという趣旨が記録されています。

### 4. 防災・災害対応と地域情報を結びつける

防災もCode for SAITAMAの重要な活動領域です。浦和での防災をテーマにしたマッピング、さいたま市マッチングファンド関連の防災アプリ・防災情報、別所沼公園防災ピクニックでのブース出展、協働型災害訓練関連の共有、そして2024年の能登半島地震に関するOpenStreetMapクライシスマッピングのもくもく会など、災害時・平時の両方に役立つ地域情報の整備に関わってきました。

Code for SAITAMAの防災に関する活動は、防災を特別な専門領域として切り離すのではなく、地図、データ、まち歩き、市民参加、地域のつながりと組み合わせて扱っている点に特徴があります。

### 5. 学びと交流の場を継続的につくる

イベント記録には、Meetup、もくもく会、地図の勉強会、D3.js勉強会、Arduinoワークショップ、IoT相談会など、学びと交流を目的とした活動も多く残っています。大きな成果物をつくるイベントだけでなく、参加者が知識を持ち寄り、試し、相談し、次の活動のきっかけをつくる場が継続的に設けられていました。

特に2020年以降は、オンライン開催のMeetupやもくもく会が増えています。COVID-19の影響下でも、お花見マッピングパーティをオンライン化したり、ZoomやMessengerルーム、Discordなどを使った活動を行ったりして、活動の形を変えながら継続していたことがわかります。

## 活動領域

Facebookアーカイブから見える主な活動領域は次の通りです。

- オープンデータの利活用
- OpenStreetMapを使ったマッピング
- 地域課題をテーマにしたアイデアソン
- オープンデータや地域情報を使ったハッカソン
- 防災・災害対応・クライシスマッピング
- アーバンデータチャレンジ、チャレンジオープンガバナンス関連活動
- SDGs、観光、農業、子どもの居場所、暑さ対策、スポーツによる地域活性化などのテーマ検討
- D3.js、GIS、地図表現、主題図づくりに関する学習
- Arduino、IoT、電子工作に関するワークショップ
- Code for Japan Summitなど、他地域のCode forコミュニティとの連携

## 活動の歩み

### 2014年: 立ち上がりと初期の実践

2014年には、Hack for クリテリウム、D3.js勉強会、浦和マッピングパーティなどが記録されています。さいたま新都心で開催されるクリテリウムをきっかけに、観光客の回遊、地域情報発信、地図やICTの活用を考えるハッカソンが行われました。また、OpenStreetMapを活用した地域防災のためのマッピングも始まっています。

### 2015年: オープンデータとマッピングの本格展開

2015年は、オープンデータアイデアソン、オープンデータハッカソン、International Open Data Day、川越のお花見マッピングパーティ、Arduinoワークショップ、さいたま市マッチングファンド関連のアイデアソン・ハッカソン・マッピングパーティなど、多くの活動が集中した年です。

この年の記録からは、オープンデータを地域課題解決に結びつける流れと、マッピングパーティを通じて地域情報を集める流れが、Code for SAITAMAの活動の柱として形づくられていったことが見えてきます。

### 2016年: 主題図、UDC、防災、地域連携

2016年には、オープンデータデイ、熊谷お花見マッピングパーティ、ビアマッピングパーティ、主題図づくり、アーバンデータチャレンジ、IoT相談会などが記録されています。さいたま市との共催事業をふまえ、活動のまとめとしてInternational Open Data Dayに参加したという記述もあります。

この時期には、地理情報や主題図を使って地域課題を見える化する方向性が強く表れています。

### 2017年: 地図の勉強会と観光テーマ

2017年には、地図の勉強会が連続して開催され、OpenStreetMapやGISに関する学びの場が継続しました。また、熊谷から埼玉の観光を考えるアイデアソン／ハッカソンも記録されています。地図を作るだけでなく、観光や地域資源の活用と結びつける視点が見られます。

### 2019年: バリアフリーと地域資源のマッピング

2019年には、車いすマッピングパーティや岩槻のお花見マッピングパーティが記録されています。車いすマッピングパーティでは、大宮盆栽美術館や周辺地域を対象に、バリアフリー情報や地域情報の可視化につながる活動が行われたと考えられます。

### 2020年: オンライン化とSDGs

2020年は、COVID-19の影響を受けながらも、オンラインMeetup、オンラインお花見マッピングパーティ、International Open Data Day、SDGsアイデアソン・ハッカソンなどが行われました。イベント説明には、オンライン開催への切り替えや、Zoomなどの利用が明記されています。

SDGs関連のイベントでは、農業遺産、狭山茶、スマートシティ、withコロナを想定した日常事業との接続など、地域の将来像を広く捉えるテーマが扱われています。

### 2021年: COG・UDCと熊谷での展開

2021年には、International Open Data Day、COG2021熊谷ミートアップ、UDC2021埼玉拠点Meetupなどが記録されています。熊谷市の「ラグビータウン熊谷」「暑さ対策日本一の街」などをテーマに、地域課題を自分ごととして考える場が設けられました。

立正大学、熊谷市、Code for Kumagaya、アーバンデータチャレンジ埼玉拠点などとの連携も見られます。

### 2022年: チャレンジオープンガバナンスと熊谷

2022年には、チャレンジオープンガバナンス2022 in 熊谷のキックオフが記録されています。テーマとして、スポーツ熱中都市、子どもの居場所、農産物のブランド化が掲げられ、熊谷市民活動支援センターを会場に、インプットワーク、アイデアソン、チームビルディング、プレゼンテーションが行われました。

### 2023年から2024年: 防災・災害対応、UDCへの継続的関心

2023年以降の投稿記録には、協働型災害訓練、ICS、UDC2024キックオフシンポジウムへの参加、2024年1月の能登半島地震に関するOpenStreetMapマッピングプロジェクトへの賛同と「もくもく会」の開催が残っています。

活動数は初期のように多くはないものの、防災、災害対応、オープンデータ、マッピングへの関心が継続していることがわかります。

## Code for SAITAMAらしさ

Code for SAITAMAらしさは、技術そのものを目的にするのではなく、地域の具体的な課題や場所、人の動きと結びつけて扱うところにあります。地図を作ること、データを使うこと、アプリを考えること、電子工作を学ぶことは、それぞれ独立した活動でありながら、どれも「地域をよく見る」「地域の情報を共有する」「市民が参加できる形にする」という方向につながっています。

また、活動の多くはワークショップ形式で行われています。参加者がただ話を聞くのではなく、歩く、調べる、入力する、考える、手を動かす、発表する、といったプロセスを含んでいます。この実践的な場づくりが、Code for SAITAMAの活動をアーカイブするうえで重要な視点です。

## アーカイブサイトで伝えたいこと

アーカイブサイトでは、単なるイベント一覧ではなく、Code for SAITAMAがどのような問いを持ち、どのような地域と関わり、どのような方法を試してきたのかを伝えることが重要です。

特に次の観点を強調すると、活動の全体像が伝わりやすくなります。

- 埼玉県内各地で、地図とデータを使った市民参加型の活動を続けてきたこと
- オープンデータを、地域課題を考えるための実践的な素材として扱ってきたこと
- マッピングパーティを通じて、地域を見る・歩く・記録する文化を育ててきたこと
- アイデアソンとハッカソンを通じて、考える場と作る場をつないできたこと
- 防災、観光、農業、子どもの居場所、暑さ対策、バリアフリーなど、幅広い地域テーマに関わってきたこと
- 大学、行政、地域団体、他地域のCode forコミュニティと連携してきたこと
- オンライン化や災害対応など、社会状況に応じて活動形態を変えてきたこと

Code for SAITAMAは、埼玉県を拠点に活動するシビックテックの非営利コミュニティです。OpenStreetMapを使ったマッピングパーティ、オープンデータのアイデアソン・ハッカソン、International Open Data Day、アーバンデータチャレンジ、防災や地域情報の可視化などを通じて、市民、行政、大学、地域団体がともに学び、考え、手を動かす場をつくってきました。

### 詳細版

Code for SAITAMAは、2014年からFacebook上に活動記録が残る、埼玉県発のシビックテック・コミュニティです。活動の中心には、オープンデータ、OpenStreetMap、地域課題解決、アイデアソン、ハッカソン、もくもく会、ミートアップがあります。

公共データや地域の情報を、誰かが整備してくれるものとして待つのではなく、市民自身が歩き、調べ、記録し、共有し、使ってみる。Code for SAITAMAは、そうした実践の場を埼玉県内各地でつくってきました。防災、観光、バリアフリー、農業、子どもの居場所、暑さ対策、SDGsなど、扱うテーマは時代や地域の課題に応じて変化しながらも、一貫して「テクノロジーを活用したアクションを創発する」ことを目指してきました。
