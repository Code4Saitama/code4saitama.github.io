## Code for SAITAMAについて

Code for SAITAMAは、埼玉県内の地域課題に対して、IT、オープンデータ、地理情報、OpenStreetMapなどの技術や知見を活用してきたシビックテック団体です。特定の市町村だけに閉じず、県内外のコミュニティと連携しながら、マッピングパーティ、アイデアソン、ハッカソン、勉強会、地域活動の支援などを行ってきました。

活動の中心にあるのは、地域を知り、歩き、記録し、共有することです。地図づくりやデータ活用は、みんなで同じ地域を見つめるための道具。市民、行政、地域団体、技術者がゆるやかにつながる場をつくってきました。

## このサイトについて

このサイトは、Code for SAITAMAの公式ページです。現在は、これまでの活動を見つけやすくするため、イベント記録や写真、関連資料を中心に公開しています。

本文情報があるイベントは詳細ページを作成し、告知のみ、または内容確認中のものは年表のみの掲載にしています。過去の記録を整理しながら、Code for SAITAMAがどんなことを大切にしてきたのかも伝わるようにしています。

写真は、イベントとの対応を確認できるものを優先して掲載しています。トップのスライダーでは、活動の雰囲気を伝えるためにイベントと直接紐づかない写真も使用していますが、キャプションは写真から無理なく読み取れる範囲に限定しています。

外部発表資料、GitHub、Code for Japanネットワーク、他コミュニティとの交流など、Facebookバックアップだけでは補いきれない情報は、[関連資料](research.html)に整理しています。

## 掲載範囲

公開に適さない個人情報、Messenger、フォロワー、端末情報、IPを含むメタデータなどは、このサイトには掲載していません。公式ページとして、公開できる情報をていねいに選びながら整理しています。
