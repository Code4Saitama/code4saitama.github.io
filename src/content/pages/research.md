## このページの位置づけ

このページは、Code for SAITAMAの活動をもう少し深く知るための補助資料です。イベント記録を主軸にしつつ、GitHub、Code for Japanネットワーク、外部登壇資料、公開FBグループで共有された他地域の事例など、公開情報から確認できる周辺文脈を整理しています。

サイト内では、Facebookページのエクスポートを「FBページ」、公開Facebookグループから活動単位に再編集した情報を「FBグループ」、公開情報の追加調査を「DeepResearch」と表示します。複数の情報源で同じ活動を確認できた場合は、一つの記録に統合して複数タグを付けています。

関連資料には、活動の背景を理解するうえで重要なものと、今後さらに確認が必要なものが混在しています。確認中の情報は、参考メモとして控えめに扱います。

## 基礎情報

Code for SAITAMAは、埼玉県を活動範囲とするシビックテック団体として、GISやOpenStreetMapの要素を多く含む活動を行ってきました。2014年1月の発足以降、マッピングパーティ、アイデアソン、ハッカソン、勉強会などを継続的に開催してきた記録が残っています。

設立趣旨は「SAITAMAのITの力で、社会課題の解決を図ることで、市民をわくわくさせる」ことです。ロゴは埼玉の勾玉とマップピンを表し、地域性と地理情報への関心を重ねたものです。

## Code for SAITAMAの位置づけ

このサイトでは、Code for SAITAMAを、さいたま市単位のCode for Saitama-Cityとは別の、埼玉県全域を視野に入れた広域的なシビックテック活動として整理しています。Code for Japanのブリゲード一覧にはCode for Saitama-CityとCode for TODAが掲載されていますが、Code for SAITAMAはそれらとは異なる活動単位として記録します。

県内の自治体別ブリゲードと並列に比較するよりも、GIS、OpenStreetMap、オープンデータ、マッピングの知見を持つ広域コミュニティとして、各地の活動を支えてきたレイヤーとして読むのが自然です。

## 技術的な特徴

Facebookバックアップ内のイベントを見ると、マッピングパーティ、地図の勉強会、主題図、LocalWiki、OpenStreetMap、UDC/COG、防災、SDGsなど、地理情報と地域課題をつなぐ活動が目立ちます。GitHub上の公開リポジトリにも、ドローンタイルサーバ、避難所データ、地図表示、フードバンクなど、活動と接続して読むことのできる技術的アウトプットが残っています。

## アーカイブ構築上の注意

「Code for SAITAMA」は、検索時に金融コードなどの無関係な情報が混入しやすい名称です。このサイトでは、単純なキーワード一致ではなく、公開済みの活動記録、GitHub、Code for Japanネットワーク、イベント名、地図・OpenStreetMap文脈の一致を重視して整理しています。

個人名、役職、連絡先、プロフィールリンクなどは、活動の理解や引用元の特定に不可欠な場合を除いて掲載しません。確認が十分でない情報は、サイト本文では抑制し、補足メモとして扱います。
