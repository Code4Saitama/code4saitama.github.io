年に一度、世界で同時にイベントを開催するオープンデータのお祭り、インターナショナルオープンデータデイ2016が、2016年3月5日に開催されます。

Code for SAITAMA でも昨年に引き続きオープンデータデイのイベントを開催します。

場所：アーバンデザインセンターみその
日時    2016年3月5日 土曜日  13時から17時まで

今年度のCode for SAITAMAは、さいたまマッチングファンドでさいたま市と共催のマッピングパーティー、アイデアソン、ハッカソンを2回づつ行いました。他にも Code for Japan Summit 2016 をはじめ各地で活動の幅を広げておりました。そういった活動のまとめとして、このインターナショナルオープンデータデイ2016に参加します。
