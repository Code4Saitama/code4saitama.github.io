## 【しばらく第三水曜の夜に開催します】

こんにちは、Code for SAITAMAです。
2014年1月発足のCode for SAITAMAも7年目となります。
今年は「イベント月イチ開催」の初心に帰って定期的に集まっていくことにしました。まずは浦和のさいたま市民活動サポートセンターに集まりましょう！
はじめましての皆様も、お久しぶりの皆様も、よろしくおねがいします！

日時：2020年2月19日 19:00〜21:00（出入り自由）
場所：さいたま市民活動サポートセンター（浦和PARCO9階）

内容：
・Code for SAITAMAとは
・あらためて自己紹介、できること、やりたいこと
・グループディスカッション
・決まったこと発表

終了後、希望者で懇親会します。
