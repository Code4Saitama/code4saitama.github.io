11/6-8に池袋の豊島区役所旧庁舎にて「Code for Japan Summit 2015」が開催されます。

2日目の11/7（土） 13:00-14:30の枠でCode for SAITAMA企画「マッピングパーティーのつくりかた」があります。その実践編としてマッピングパーティーをやります！
会場周辺を歩いて、テーマにそってマッピングをしましょう。

参加費：（Code for Japan Summit 2015のチケットをご登録下さい（無料）

持ち物：とくにいりませんが、ノートパソコンがあれば入力作業が捗ります

※雨天決行、状況によっては屋内作業となります。
