4月のCode for SAITAMAのイベントは、熊谷の国宝歓喜院聖天堂でのマッピングパーティーです。多くの方の参加をお待ちしてます。

妻沼聖天山　歓喜院聖天堂
http://www.city.kumagaya.lg.jp/kanko/midokoro/menumasyoudenzan/index.html

世界遺産の宝庫、京都では毎月マッピングパーティーが行われています。写真1は二条城のマッピングの結果です。このようにデータを作っておけば、観光マップやレストランガイド、商店街のガイドなどの印刷物にも使えます。

Code for SAITAMAでは、これまでに、大宮、さいたま新都心、盆栽村、岩槻、川越等でマッピングパーティーを開催し、まちづくりとのコラボを行ってきました。

＊マッピングパーティーというのは、皆で自由に使える地図（オープンストリートマップといいます。通常OSMと呼ばれています。）を作るワークショップです。史跡めぐりと併せて行えば歴史の勉強にもなりますし、ウォーキングと併せて行えばまちの発見が出来るなど色んな組み合わせがあります。
