# Facebook group archive

公開Facebookグループから取得した記録を、Code for SAITAMAの活動年表・テーマ・関連資料へ統合するための編集用データです。投稿者・コメント投稿者・プロフィールURLなど、活動の理解に不要な個人情報は公開用データから削除しています。

- `public_records.json`: 年表・テーマ・関連資料に統合する公開用記録
- `posts.json`: 匿名化済みの投稿・要約・コメント
- `group_events.json`: 匿名化済みのグループイベント情報
- `*_images_manifest.json`: 保存画像の識別子と保存先（人物名・元URLは除去）
- `event_filter_manifest.json`: レビュー結果の集計
- `full_crawl_report.json`: 取得結果

投稿・FBイベントの独立した公開ページは設けず、公開用記録は内容に応じて年表・テーマ別・関連資料に表示します。

投稿 388件、コメント 454件、投稿画像 263点、コメント画像 7点、グループイベント 123件、イベント画像 72点。
